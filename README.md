# Outriq Web

Next.js marketing site for **Outriq** — smarter outbound for modern teams.

## Stack

- Next.js 16 (App Router)
- React 19
- Template layout/CSS (dark theme) with Outriq brand overrides

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Marketing copy lives in [`src/lib/outriq-content.ts`](src/lib/outriq-content.ts). Logos are in [`public/outriq-logo/`](public/outriq-logo/) (`1.svg` dark UI wordmark, `2.svg` light UI wordmark, `3.svg` icon).

## Build

```bash
npm run build
npm start
```
